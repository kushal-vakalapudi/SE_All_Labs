## Report availability

The supplied PDFs cover Labs 1–3. The linked Lab 4–7 repositories did not
contain lab-report PDFs, so their available source files and documentation are
included instead. Lab 7's README mentions an evidence PDF, but that file was
not present in the linked repository and is not included here.

The Lab 4–7 folders contain snapshots of the files in their linked repositories;
their original Git histories are not embedded in this collection.
