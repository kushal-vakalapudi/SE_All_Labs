# Maze Runner

A Pygame maze game with procedural generation, three difficulty levels, a shortest-path hint, fog of war, and a persistent completion-time leaderboard.

## Setup

```bash
python -m pip install -r requirements.txt
python main.py
```

Choose a difficulty by clicking its button or pressing `1` (Easy), `2` (Medium), or `3` (Hard). Each game creates a fresh maze.

## Controls

| Key | Action |
|-----|--------|
| W / UP | Move up |
| S / DOWN | Move down |
| A / LEFT | Move left |
| D / RIGHT | Move right |
| H | Toggle the shortest-path hint |
| R | Generate a new maze at the current difficulty |
| ESC | Return to difficulty selection |

The fog reveals a circular area with a radius of three maze cells around the player. Completion times are saved to `leaderboard.json`; the five fastest times are shown on the win screen.

## Lab features

- **Shortest-path hint:** breadth-first search finds and highlights a shortest route from the start to the exit.
- **Fog of war:** a transparent circular opening reveals nearby maze cells while the rest remains dark.
- **Timer leaderboard:** completed runs are persisted in `leaderboard.json`, sorted by time, and capped at five entries.
- **Difficulty tiers:** Easy (10x8), Medium (15x13), and Hard (20x18) can be selected before play.
- **Wall collision:** player movement respects maze passages and stays inside the maze.

## Tests

Run the unit tests with:

```bash
python -m unittest discover -s tests -v
```
